# 📚 Curso de Next.j
<br/>
Este repositório contém exemplos práticos e exercícios desenvolvidos ao longo de um curso de Next.js, cobrindo desde conceitos básicos até recursos avançados do framework.
Cada pasta numerada corresponde a uma etapa específica do aprendizado, facilitando o acompanhamento do progresso.

📂 Estrutura do Projeto
1_hello_world_next → Primeiro projeto em Next.js, com uma página inicial simples.

2_pages_e_roteamento → Criação de múltiplas páginas e introdução ao roteamento automático.

3_nested_routes → Rotas aninhadas e organização de páginas em subpastas.

4_navegando_entre_pags → Navegação entre páginas com o componente Link.

5_componentes → Criação e reutilização de componentes React dentro do Next.js.

6_layout → Implementação de layouts reutilizáveis.

7_css_no_next → Estilos com CSS Modules e diferentes formas de estilização.

8_meta_dados → Uso de metadados e personalização do <Head>.

9_assets → Utilização de imagens, ícones e outros assets no Next.js.

10_fetch_data → Fetch de dados com getStaticProps e getServerSideProps.

11_dynamic_routes → Rotas dinâmicas e parâmetros de URL.

12_dynamic_with_data → Rotas dinâmicas consumindo dados externos.

13_404 → Página personalizada de erro 404.

14_inspecao_de_build → Análise e inspeção do build do Next.js.

15_pokenext → Projeto final integrando os conhecimentos adquiridos (exemplo prático estilo “Pokédex”).

🚀 Tecnologias Utilizadas

Next.js

React

CSS Modules / Estilização nativa

Fetch API / Consumo de dados

▶️ Como Executar

Clone este repositório:

git clone https://github.com/seu-usuario/curso_nextjs_yt.git
cd curso_nextjs_yt-main


Entre em qualquer uma das pastas de exemplo, instale as dependências e execute:

npm install
npm run dev


Acesse no navegador:

http://localhost:3000

📌 Objetivo

Servir como material de estudo e prática para quem deseja aprender Next.js de forma progressiva, com exemplos que vão do básico ao avançado.
